<h1 align="center">수업내용</h1>
<p align="center">방과후 강사를 위한 교재 주문·반품 계산과 학교별 수업 기록 앱</p>

---

## 소개
여러 학교에 출강하면서 학기마다 교재를 주문하고 견적서를 받는 과정을 한곳에서 관리하는 휴대폰용 웹앱(PWA)입니다.
주문 수량과 견적 수량만 적으면 **반품 수량과 금액이 자동으로 계산**되고, 학교별로 **지난 5년간 어떤 교재로 수업했는지** 확인할 수 있습니다.

## 주요 기능
| 탭 | 기능 |
|---|---|
| **주문내역** | 년도·학기별로 학교마다 1부·2부 교재의 제목, 단가, 주문·견적 수량 입력 → 반품 수량·금액 자동 계산, 견적서 교재비 합계, 다른 학교로 교재 이동 기록, 메모 |
| **정리** | 학기별 반품 내역 표, 올해 1·2학기 교재비·반품 합계, 엑셀용 표 복사 |
| **수업 내용** | 학교별 5년간 1부·2부 교재와 학년, 학년을 고르면 그 학생들이 이전 학년에 배운 교재 확인 (중복 교재 표시) |
| **학교** | 년도별 수업 학교 관리, 다음 해로 학교 넘기기, 교재 없이 수업한 학교, 학교별 수업 년도 기록 |

## 사용 방법
1. **학교** 탭에서 올해 수업하는 학교를 추가합니다.
2. **주문내역** 탭에서 년도·학기를 고르고 교재 제목, 단가, 주문 수량을 입력합니다.
3. 견적서를 받으면 견적 수량을 입력합니다. 반품 수량은 자동으로 계산됩니다.
4. 학기가 끝나면 **정리** 탭에서 합계를 확인하고, 주문내역 탭 맨 아래 **백업**을 눌러 저장합니다.

## 설치 (홈 화면에 앱으로 추가)
- **안드로이드(크롬)**: 메뉴 ⋮ → **앱 설치**
- **아이폰(사파리)**: 공유 → **홈 화면에 추가**

한 번 열면 인터넷이 없어도 실행됩니다.

## 데이터 저장
- 모든 기록은 **사용하는 휴대폰(브라우저) 안에만** 저장되며 서버로 전송되지 않습니다.
- 휴대폰을 바꾸거나 브라우저 데이터를 지우면 기록이 사라지므로, 학기마다 **백업**해 두세요.
- 백업 파일 이름: `수업내용_yy-mm-dd.json` → 다른 기기에서 **복구**로 불러올 수 있습니다.

## 파일 구성
```
index.html             앱 본체
manifest.webmanifest   앱 이름·아이콘·테마 색 (PWA 설정)
sw.js                  오프라인 실행용 서비스 워커
icons/                 앱 아이콘
```

## 업데이트할 때
`index.html`을 고쳐서 다시 올린 뒤, `sw.js` 맨 위의 `VERSION` 값을 `v2`, `v3`처럼 올려 주세요. 그래야 설치된 앱에 새 버전이 반영됩니다.
